# Модульный Telegram‑бот на aiogram

Модульный Telegram‑бот с динамической загрузкой модулей и автоматическим мониторингом их работоспособности. Построен на библиотеке `aiogram` (версия 3+).

## Особенности

* **Модульная архитектура** — функционал разбит на независимые модули.
* **Динамическая загрузка** — модули подключаются при запуске бота.
* **Автоматическое отключение** нерабочих модулей с логированием ошибок.
* **Централизованная конфигурация** — все модули описываются в одном месте.
* **Детальное логирование** — полный отчёт о загрузке модулей.
* **Устойчивость к ошибкам** — сбой одного модуля не останавливает работу бота.

## Установка и настройка

### Шаг 1. Клонирование проекта

```bash
git clone https://github.com/Nepegnik142/nepegnik-telegram-modules-bot.git
cd telegram-bot
```

### Шаг 2. Создание виртуального окружения (рекомендуется)

```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

### Шаг 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

Содержимое `requirements.txt`:
```
aiogram>=3.0.0
```

### Шаг 4. Настройка конфигурации

1. Получите токен бота у @BotFather в Telegram.
2. Откройте `main.py` и замените `YOUR_BOT_TOKEN_HERE` на реальный токен:

   ```python
   BOT_TOKEN = "1234567890:ABCdefGHIjklMNOpqrsTUVwxyz"
   ```

3. При необходимости настройте конфигурацию модулей в `modules_config` внутри `main.py`:

   ```python
   modules_config = [
       {
           "module_name": "example",
           "module_version": "1.0",
           "module_path": "example.py"
       },
       # Добавьте другие модули по необходимости
   ]
   ```

## Запуск бота

```bash
python main.py
```

После запуска бот начнёт загрузку модулей и выведет отчёт в консоль.

## Конфигурация модулей

Все модули описываются в списке `modules_config` в `main.py`. Каждый модуль имеет параметры:

* `module_name` — уникальное имя модуля для логирования.
* `module_version` — версия модуля.
* `module_path` — путь к файлу модуля относительно папки `modules/`.

Пример конфигурации:
```python
modules_config = [
    {
        "module_name": "example",
        "module_version": "1.0",
        "module_path": "example.py"
    },
    {
        "module_name": "admin",
        "module_version": "1.1",
        "module_path": "admin.py"
    }
]
```

## Создание собственных модулей

Чтобы добавить новый модуль:

1. Создайте файл в папке `modules/` (например, `modules/my_module.py`).
2. В файле создайте роутер и определите обработчики:

   ```python
   from aiogram import Router
   from aiogram.types import Message
   from aiogram.filters import Command

   router = Router()

   @router.message(Command("mymodule"))
   async def cmd_mymodule(message: Message):
       await message.answer("Привет из моего модуля!")
   ```
3. Добавьте описание модуля в `modules_config` в `main.py`.
4. Перезапустите бота.

## Команды бота

Доступные команды зависят от подключённых модулей. Примеры:

* `/start` — приветственное сообщение.
* `/help` — справка по командам.
* `/admin` — админ‑панель (если модуль подключён).
* `/echo [текст]` — повторение текста (если модуль поддерживает).

## Логирование и мониторинг

Бот выводит детальные логи в консоль:

* старт бота;
* загрузка каждого модуля (имя, версия, путь);
* ошибки загрузки (если файл не найден, отсутствует `router` и т. д.);
* итоговый отчёт (количество успешно загруженных и проблемных модулей).

## Устранение неполадок

Если модуль не загружается:

1. Проверьте, что файл модуля существует по указанному пути.
2. Убедитесь, что в модуле есть переменная `router = Router()`.
3. Проверьте код модуля на синтаксические ошибки (запустите `python modules/my_module.py` отдельно).
4. Посмотрите логи в консоли — там будет подробное сообщение об ошибке.

Частые ошибки:
* `FileNotFoundError` — файл модуля не найден по указанному пути.
* `AttributeError` — в модуле отсутствует атрибут `router`.
* `SyntaxError` — синтаксическая ошибка в коде модуля.
